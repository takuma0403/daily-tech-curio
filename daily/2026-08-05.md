### <a id="card-1"></a>🆕 ゲーミングマウスが、握った手の脈を盗み聞く——光学センサーの二重生活〔move: センサーの転用 / 領域: 無線/組み込み/ハードウェア〕

**事実**: 光学マウスの底面には、LED（または赤色レーザー）と、それを反射させて跳ね返ってきた光を読み取るフォトセンサーが入っている。本来の役目は机の模様の動きを追ってカーソル位置を動かすことだけだが、この「光を当てて反射光の変化を読む」という構成は、指先クリップ型のパルスオキシメータや腕時計型ウェアラブルが心拍を測るときに使うPPG（光電式容積脈波）センサーと物理的にまったく同じ仕組みである。血管を流れる血液量が脈打つたびに反射光の強度がわずかに揺れる、という現象を拾えばよいだけで、部品を1つも足す必要がない。

**何ができる**: マウスのファームウェア（またはUSB経由の常駐ソフト）側でこの反射光の微小な揺らぎをフィルタリングするだけで、普段どおりPCを操作している最中の心拍数をリアルタイムで抜き出せる。実際に研究では光学マウスにGSR（皮膚電気反応）センサーを足したものが、ストレスを誘発するタスク中の心拍上昇と皮膚コンダクタンス上昇を検出できることが確認されている。ウェアラブルを着けさせる必要も本人に気づかせる必要もなく、「いつものマウスを使わせる」だけで交渉中・査定面談中・監視対象のPC作業中の緊張の高まりを外部へ送信できてしまう——キーボードの打鍵ではなく、握った手そのものを盗聴器にする発想。

**技術の魅力**: 心拍センサーとポインティングデバイスは開発の目的も文脈もまったく別物なのに、「LEDで照らして反射光を読む」という最下層の物理層だけを見ると同一のハードウェアだったという事実が効いている。新しいセンサーを足さず、既存のトラッキング用光学系にただ違う意味（モーション量ではなく脈波）を読ませるだけで、誰にも見えない生体センサーが1個ずつのデスクに標準装備されていたことになる。

**本来どこで使われてるか**: PPGは指先クリップ式パルスオキシメータやApple Watch・Fitbitなど腕時計型ウェアラブルの心拍計測で日常的に使われている標準技術。マウスへの応用も実際に学術研究として存在し、2017年の『Sensors』誌ではマルチPPGセンサーをマウスに埋め込んだ脈拍検出手法が、2023年の『Biosensors』誌ではPPGとGSRを組み込んだマウスによる職場ストレス検出システムが報告されている。
出典: https://www.mdpi.com/1424-8220/17/7/1628 / https://www.mdpi.com/2079-6374/13/1/10

### <a id="card-2"></a>🔍 掲示板を同期するためのプロトコルが、17年消えないストレージになった——NNTPの二度目の人生〔move: レガシー/廃止予定機能の蘇生 / 領域: データ/同期/ストレージ〕

**事実**: NNTP（Network News Transfer Protocol, RFC 977, 1986年）は、大学間でUsenetの議論スレッドを同期するために作られた古いプロトコルで、サーバー同士が新着記事を隣のサーバーへ次々に押し流す「フラッド型（flood-fill）複製」で全世界にコピーを広げる設計になっている。2010年代にISPが軒並み無料Usenetアクセスを打ち切り、一般には「もう死んだプロトコル」扱いになったが、専業の「保持プロバイダ」たちがそのまま運用を継続。むしろ皮肉なことに、議論の同期用に作られたこの複製の仕組みが、今では単なる巨大な冗長ストレージ基盤として機能している。

**何ができる**: 主要な保持プロバイダは2025年時点でバイナリ・テキストとも6,000日超（17年以上）のフル保持を提供しており、しかもUS東海岸・US西海岸・EUの独立したサーバー群それぞれに同じ深さの記事がまるごと複製される。つまり1つのファイルをアップロードすると、誰も中央管理していない複数の独立事業者のデータセンターに逐語的なコピーが自動的に量産される。中身の実体を指す小さな索引ファイル（NZB）だけを別途配布すれば、「何が存在するか」という薄い情報と「実データがどこにあるか」という重いストレージを分離できる——ブロックチェーン的な耐障害ストレージの発想を、合意アルゴリズムなしに素朴なゴシップ複製だけで先取りしていた。

**技術の魅力**: 誰も「単一障害点のない分散ストレージを作ろう」として設計していないのが肝。1986年当時はただ「議論を後から参加した大学のサーバーにも行き渡らせたい」というだけの動機で書かれたフラッド複製ルールが、副作用として「単一の所有者がおらず、消そうにも消しきれない」ストレージ特性を生んだ。目的と結果がここまでズレたまま30年生き延びている例は珍しい。

**本来どこで使われてるか**: 本来はUsenetのニュースグループ（掲示板の元祖）の記事をサーバー間で同期するための地味なプロトコル。今日でも実際にNewshosting・Eweka・Easynews・NewsDemonのような保持プロバイダが稼働しており、Sonarr/Radarrなど自動化ツールがNZBファイル経由でこの網を静かに使い続けている。
出典: https://www.newsdemon.com/usenet-retention / https://datahoarder.io/is-usenet-still-around/

### <a id="card-3"></a>💡 ショウジョウバエの神経が"間引く"やり方を、電波しか感じない極限デバイスに移植する——Beeping Modelの最大独立集合〔move: 異分野の手法移植 / 領域: ワイルドカード(神経科学×分散無線アルゴリズム) / レンズ: サーバー不要〕

**事実**: ショウジョウバエの神経系が作られる過程では、隣り合う候補細胞たちが「感覚器になる1個」を中央の指令なしに勝手に選び出す。各細胞はランダムなタイミングで信号を出し、隣が信号を出しているのを感知したら自分は身を引く（側方抑制）——これを繰り返すだけで、隣同士が絶対に両方選ばれない、かつ全体にまんべんなく散らばった細胞集合（グラフ理論でいう最大独立集合=MIS）が勝手に収束する。2011年、分散計算の理論家たち（Afek, Alon, Bar-Joseph, Cornejo, Haeupler, Kuhn）は、この仕組みをそのまま「ビープモデル」という無線ネットワークの数理モデルに移植した——ノードは自分のIDも近傍の数も知らず、送れる情報は「ビープ音を出す/出さない」の1ビットだけ、受け取れる情報も「誰かがビープしたか/静寂か」の2値だけという、実データを一切やり取りできない極限に貧弱な無線モデルである。

**何ができる**: この移植によって、パケットの中身どころか復調すらできないほど単純な無線ノード（電波のエネルギーが「ある/なし」しか検知できないチップ）だけで、リーダー選出やTDMAスケジューリング用のチャンネル割り当てに使えるMISを高速かつ分散的に計算するアルゴリズムが手に入る。中央のコーディネータもマスタークロックも要らず、各ノードはハエの1個の細胞と同じく「自分の隣で今誰かビープしたか」しか見ていないのに、全体として綺麗に間引かれた非干渉ノード集合が浮かび上がる。

**技術の魅力**: 普通、分散アルゴリズムは「ビットを正しく送り合える」ことを前提に組む。この移植が効いているのは真逆で、「通信すらまともにできない」という制約をそのまま活かした点にある。ハエの細胞が持つ制約（隣の状態しか感知できず、複雑な情報のやり取りができない）と、極限まで簡素化された無線チップの制約が形として一致していたからこそ、生物の解法を証明ごとほぼそのまま輸入できた。制約が弱いモデルほど生物からの部品取りが効く、という相性の良さが面白い。

**本来どこで使われてるか**: 本来は発生生物学における感覚器前駆細胞（SOP）選択の説明理論。分散計算理論でも「ビープモデル」はその後、無線センサーネットワークの資源制約下でのMIS計算・彩色・自己安定化アルゴリズムの標準的な研究対象になっており、2024年以降も自己安定化ビープMISの論文が発表され続けている。
出典: https://link.springer.com/article/10.1007/s00446-012-0175-7 / https://arxiv.org/pdf/2405.04266
