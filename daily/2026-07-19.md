### <a id="card-1"></a>📺 家中の電流のさざなみが、今見ているテレビ番組をそのまま漏らす 〔move: サイドチャネル/副作用の利用 / 領域: ワイルドカード(電力)〕

**事実**: 家庭のコンセントは電気を届けるだけの受け身の配線に見えるが、テレビの電源回路(特にスイッチング電源やバックライトのPWM調光)は、映像フレームの明暗が変わるたびに消費電流の波形を微妙に変化させる。この揺らぎは電磁干渉(EMI)として電力線に乗り、家中どのコンセントからでも、あるいはスマートメーターの計測値からでも拾い出せる。テレビ自体はネットに繋がっていなくてもよく、盗聴に必要なのは電力線への物理アクセスだけ。

**何ができる**: あらかじめ主要な映画・番組のEMI波形をデータベース化しておけば、対象の家の壁のコンセントに接続した安価な計測器一つで、いま室内でどの映画・チャンネルが流れているかを外から照合できる。スマートメーターの計測粒度が粗くても、フレームごとの明滅パターンという指紋は残るため、Non-Intrusive Load Monitoring(NILM)が本来「家電の種類」を当てる技術であるのに対し、ここでは家電の"中身"、つまり視聴内容そのものまで踏み込める。

**技術の魅力**: 攻撃者はテレビの画面はおろか部屋にすら入る必要がなく、電力インフラという生活に不可欠で誰も疑わないパイプを盗聴器に変えてしまう。エネルギー消費という「量」の情報が、映像内容という「質」の情報にまで解像度を持つという非対称性が肝で、電力会社が課金のために集めるデータが、そのままメディア視聴履歴のログになりかねない。

**本来どこで使われてるか**: 家電の消費電力波形から「洗濯機が今何行程目か」を推定するNILMは、スマートグリッドの省エネ診断や電力会社の需要予測に日常的に使われている枯れた技術。ワシントン大学のEnevらは2011年のACM CCSで、8機種のテレビの電源からのEMIだけで映像コンテンツを高精度に再構成できることを実証し、スマートメーター普及がもたらすプライバシーリスクの代表例として引用され続けている。
出典: https://dl.acm.org/doi/10.1145/2046707.2046770 / https://homes.cs.washington.edu/~yoshi/papers/ccs2011-emi.pdf

### <a id="card-2"></a>📡 電波を"わざと打ち消し合わせる"だけで、壁の向こうの人影が浮かぶ——Wi-Vi 〔move: 物理現象へのピギーバック / 領域: ネットワーク/プロトコル〕

**事実**: Wi-Fi電波は壁を透過するが、静止した壁や家具からの反射がノイズとして常に信号に混ざり込む。MITのAdibとKatabiが作ったWi-Viは、位相を反転させた2つの信号を同時に送り、動かないものからの反射同士を打ち消し合わせるという発想で、静止した背景を丸ごと消去する。残るのは、動いている物体――たとえば壁の向こうを歩く人――からの反射だけになる。レーダーのクラッタ除去と同じ理屈を、専用ハードウェアなしの民生Wi-Fiチップで実現した点が新しい。

**何ができる**: 部屋の外に置いたノートPCとアンテナ2本だけで、壁越しに何人いるか、どちらへ動いているか、単純なジェスチャーまで検知できる。カメラもマイクも室内に置かず、対象がWi-Fi機器を持っている必要すらない。侵入者検知、要介護者の転倒検知、閉じた部屋の気配を探る用途まで、"見えない場所を覗く"がケーブルレスで完結する。

**技術の魅力**: 本来は通信の邪魔でしかない多重反射・マルチパスという"欠陥"を、位相操作で逆手に取って背景除去フィルタに変えているのが効いている。電波を運び屋としか見ていなければ気づかない、電波の物理的な干渉現象そのものを情報源に転用する発想。しかも近年はこれが個々の研究のハックで終わらず、IEEE 802.11bfとしてWi-Fiの標準仕様そのものにセンシング機能を正式に組み込む動きまで進んでいる。

**本来どこで使われてるか**: Wi-Fi CSI(チャネル状態情報)を使った人検知は、2013年のACM SIGCOMMでのWi-Vi発表以降、非接触の転倒検知・呼吸モニタリング・在室検知として研究が続き、2024年にはIEEE 802.11bf(Wi-Fi Sensing)として標準化された。既存のルーターとクライアントだけで、追加センサーなしに動体検知や人数カウントをする商用製品も登場し始めている。
出典: https://people.csail.mit.edu/fadel/papers/wivi-paper.pdf / https://en.wikipedia.org/wiki/WiFi_Sensing

### <a id="card-3"></a>👂 耳の穴の"かたち"が、指紋の代わりになる——EarEcho 〔move: 人間/身体をプロトコルの一部にする / 領域: セキュリティ/認証〕

**事実**: 耳の穴(外耳道)は人によって長さも曲がり方も微妙に異なり、しかも指紋と違って外から見えない。イヤホンのスピーカーから音を鳴らし、耳の中で反射して戻ってくる音(エコー)を同じイヤホンの内蔵マイクで拾うと、その反射特性は耳の穴の形状に固有のフィルタがかかった波形になる。EarEchoは、この「誰でも持っているのに誰も見たことがない自分だけの音響フィルタ」を認証の鍵として使う。

**何ができる**: 普段聴いている音楽や音声通話の音そのものをプローブ代わりに使い、装着している間ずっと裏で本人確認をし続けられる。パスワードもPINも顔も指も出さず、イヤホンを耳に入れているという行為そのものが継続認証になる。1秒の窓で約95%、3秒に伸ばすと97.5%の精度で本人を識別できたと報告されており、スマホのロック解除や決済直前の確認をイヤホン一つで完結させられる。

**技術の魅力**: 生体認証というと指紋・顔・虹彩のように「見える身体的特徴」を使うのが定番だが、EarEchoは音の反射という物理現象を介してしか観測できない"不可視の身体の型"を鍵にする。しかも認証用に新しい音を鳴らす必要すらなく、いま流れている音楽の反射だけで済むため、ユーザー体験を一切邪魔しない継続認証が成立するという非対称性が面白い。

**本来どこで使われてるか**: 音響反射で管や空洞の形状を調べる手法自体は、建築音響や耳鼻科の診断(耳音響反射率測定)で使われてきた枯れた技術。ニューヨーク州立大学バッファロー校のJin准教授らの研究チームが2019年にACM IMWUT誌でEarEchoとして発表し、市販のワイヤレスイヤホンを流用した継続認証プロトタイプを20人の被験者で検証した。
出典: https://dl.acm.org/doi/10.1145/3351239 / https://www.buffalo.edu/news/releases/2019/09/027.html
