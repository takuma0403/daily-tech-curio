### <a id="card-1"></a>🆕 電話のプッシュ音を聞き分ける計算式が、FFTなしの超小型ウェイクワード検出器になる 〔move: 制約の極端化 / 領域: AI/メディア処理 / レンズ: 無関係な2技術の組み合わせ〕

**事実**: 1958年、Gerald Goertzelは *American Mathematical Monthly* 誌に有限三角級数を評価する再帰式を発表した。これは実質、DFT(離散フーリエ変換)の中から狙った1本の周波数成分だけを、2次のIIRフィルタの再帰計算だけで取り出す方法になる。FFTのように帯域全体をまとめて計算する必要がなく、乗算・加算を数回、信号長ぶんループするだけで済む。この性質のおかげで、電話網のプッシュ信号(DTMF)を安価なチップで復号する標準アルゴリズムとして、70年近く使われ続けている。

**何ができる**: FFTライブラリもFPUも持たない8ビットMCUの上で、「この1周波数(1音)が鳴ったら起きる」という超軽量な常時待受け回路が組める。数バイトの状態変数をサンプルごとに更新するだけなので、コイン電池駆動のバッジや玩具でも、決まった周波数のブザー音・超音波ビーコン・口笛の一音だけに反応する“耳”を作れる。狙う周波数を増やせばGoertzelインスタンスを並べるだけで多チャンネル検出にもなり、ニューラル系のウェイクワード検出器より桁違いに軽い。

**技術の魅力**: 「フーリエ変換は全体を計算しないと使えない」という思い込みを崩し、必要な周波数1本だけをつまみ出すという発想の非対称性が効いている。電話網の押しボタンを聞き分けるためだけに磨かれてきた古い数式が、オンデバイスML全盛の今でも「1トーンだけ聞き分ける」用途では最新のニューラルネットより軽いという逆転が起きているのが面白い。1958年の電話工学の数式と、2020年代のIoTウェイクワードチップという、本来なら交わらない2つの時代の技術が同じ仕事を取り合っている。

**本来どこで使われてるか**: 固定電話・IVR(自動音声応答)・留守番電話・モデムのDTMF復号が本業で、今もほぼ全ての電話交換機やコールセンターシステムの中で動いている。無線の世界でも、特定の周波数だけを通すサブオーディブルトーン(CTCSS)のスケルチ解除に同じ原理が使われ、AVR ATmega128のようなFPUなし8ビットMCUでリアルタイムDTMF検出を行う実装例も公開されている。

### <a id="card-2"></a>🔍 1970年代のポケベル規格が、病院の“命綱”として今も鳴り続けている 〔move: レガシー/廃止予定機能の蘇生 / 領域: 無線・組み込み・ハードウェア〕

**事実**: POCSAG(Post Office Code Standardisation Advisory Group)は1970年代末にイギリス郵政省主導で策定された、片方向ポケベル向けの無線データ規格。1200/2400bpsのFSK変調でVHF/UHF帯に平文のままメッセージを載せ、広域一斉送信する、暗号化もハンドシェイクも持たない極めてシンプルな仕組みだ。携帯電話網に淘汰されて久しいはずが、今も現役で使われ続けている。

**何ができる**: 病院のMRI室・鉛遮蔽された放射線科・地下の手術室など、携帯電波が届かない、あるいは干渉してはいけない環境でも、ワンウェイの広域無線だからこそ確実に鳴らせる。基地局増設もSIMも不要で、送信側1台からエリア内の全端末へ同時に着信させられるため、大規模インシデント時に医療スタッフを一斉召集する用途に今なお使われている。RTL-SDRのような20ドル級のUSBドングルとフリーソフトさえあれば、誰でもこの電波を受信してデコードできてしまう。

**技術の魅力**: 「新しい方が優れている」という直感に反し、機能を削ぎ落としたが故の単純さと信頼性が、複雑化した携帯網より有事に強いという逆転が面白い。輻輳もアプリのクラッシュも起きようがない片方向ブロードキャストという設計が、廃止予定と言われ続けて半世紀近く現役という異例の長寿を支えている。ただしその単純さは弱点そのものでもあり、暗号化ゼロという設計は今のセキュリティ観からは丸裸に近い。

**本来どこで使われてるか**: 病院・消防・自治体の緊急通報システムが主戦場で、英国の救急医療スタッフの多くは今もPOCSAGポケベルを携帯し、携帯網が輻輳・停止する大規模災害時のフォールバックとして運用されている。産業プラントの警報系や、電波の届きにくい地下施設の呼び出しにも採用例があり、平文ゆえの脆弱性が繰り返し指摘されながらも置き換えが進んでいない。

### <a id="card-3"></a>💡 中央管制なしで、世界中の船が発信タイミングを勝手に譲り合っている 〔move: 異分野の手法移植 / 領域: ワイルドカード(海事・分散システム)〕

**事実**: 船舶が位置・速度・針路を自動でVHF放送し続けるAIS(Automatic Identification System)は、SOTDMA(Self-Organizing TDMA)という通信方式で動いている。ふつうのTDMAは基地局が「あなたはこの時間枠」と割り当てるが、SOTDMAには基地局が存在しない。GPS由来のUTC時刻を基準に1分間を2250個・26.6ミリ秒のスロットに分割し、各船は「次はこのスロットを使う」という予約情報を自分の送信に載せて周囲に宣言し、他船はそれを聞いて空きスロットを避ける——これを外洋を航行する何万隻もの船が、事前の通信規約の調整なしに自律的にやってのける。

**何ができる**: 中央のスケジューラを一切置かずに、多数のノードが衝突を避けながら公平にタイムスロットを共有する分散スケジューリングの実例として、そのまま設計図を借用できる。実際にSOTDMAの発想は、航空機同士が位置情報を放送し合うVDL Mode 4のような別の広域センサーネットワークにも転用されており、中央サーバーを置けない・置きたくない群制御(ドローン群、車車間通信、災害時のメッシュ無線)のスロット調停ロジックの土台として研究されている。

**技術の魅力**: 「早いもの勝ち」で衝突を許すのではなく、「次に使う枠を先に宣言してから使う」という一手間だけで、中央調停なしの公平性が成立してしまう非対称性が効いている。参加者が増えるほど密になる海域(港湾)でも、各船が周囲の宣言を聞いて自分の予約を動的にずらすため、破綻せず緩やかに縮退する。海図の余白を埋めるための地味な仕様が、実は無政府状態でも秩序を作る分散合意の教科書的な一例になっている。

**本来どこで使われてるか**: 本業は船舶の衝突回避と海上交通管制で、国際海事機関(IMO)がSOLAS条約対象の大型船に搭載を義務付けている。一方でこの“自己申告制”の弱点を突く形で、制裁対象国向けの原油タンカーがAIS発信そのものを止めたり位置を偽装したりする「ダークフリート」が急増しており、2025年には位置偽装インシデントが半期平均比19%増と報告されるなど、自己申告の善意を前提にした仕組みの限界も同時に露呈している。
