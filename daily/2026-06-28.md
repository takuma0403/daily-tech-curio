### <a id="card-1"></a>🌌 宇宙線ミューオンで"見えない中"を透視する 〔move: 物理現象へのピギーバック / 領域: 素粒子物理〕

**事実**: 宇宙線が大気に衝突して生まれるミューオンは、毎分約1万個が1m²に降り注いでいる。物質を透過する力はX線の桁違い上で、数十メートルの岩石や鉄をも通り抜ける。重要なのは、密度の違う物質を通るとミューオンが散乱・吸収される量が変わる点だ。検出器を構造物の周囲に置いて到達数を数えるだけで、内部の密度分布が浮かび上がる——誰に頼んでもいないのに、宇宙が常時スキャンし続けているのと同じことになる。これがミューグラフィ（muography）。

**何ができる**: シンチレーター板やエマルションフィルム製の検出器を対象物の周囲や内部に設置し、数日〜数週間データを積算すれば内部の空洞・密度分布の断面図が取れる。医療CTや工業X線では絶対に届かない「大型構造物の内部」を非破壊で見られる。放射線源を用意する必要がなく、被曝リスクもない。燃料デブリのような高放射線環境でも検出器を遠ざけられるため、安全にスキャンできる。

**技術の魅力**: 誰も"送信していない"放射線を"受信するだけ"で成立するという非対称性が核心だ。大気が無限の自然ビーム源として機能し、装置は完全に受動的でいられる。X線CTならば線源と検出器で対象を挟む必要があるが、ミューグラフィはピラミッドの外に検出器を1枚置くだけでいい。「送信者なき断層撮影」という構造が、既存のイメージング技術とはまったく異なる制約環境で機能する。

**本来どこで使われてるか**: 火山内部の溶岩だまりをモニタリングするvolcanology分野が先行応用。2017年の ScanPyramids プロジェクト（名古屋大学・CEA・カイロ大連合）ではクフ王のピラミッド内に全長30m超の未知の空洞が発見され、Nature誌に掲載された。東京電力・東北大学らは2012年以降、福島第一原発1号機の炉心に残る燃料デブリをミューグラフィで推定し、ロボットでは近づけない状況でも炉内状況を把握した。港湾のコンテナ核物質検査や橋梁の構造劣化診断にも実用化が進んでいる。
出典: https://en.wikipedia.org/wiki/Muon_tomography / https://cerncourier.com/a/cosmic-rays-for-cultural-heritage/

### <a id="card-2"></a>💡 握手でデータが流れる——人体を"ケーブル"にする通信 〔move: 人間/身体をプロトコルの一部にする / 領域: 生体通信 / レンズ: オフライン完結〕

**事実**: 人体（皮膚・筋肉・体液）は電気を通す。Galvanic Coupling（GC）型の体内通信（Intrabody Communication, IBC）は、皮膚に密着した電極から微弱な電流を注入し、体組織をそのまま伝送路として使う技術だ。動作周波数帯は10kHz〜1MHz、注入電流は最大許容値の1/20以下でも通信が成立する。Bluetooth・NFC・WiFiと根本的に異なるのは、電波を体外に漏らさない点——傍受するには文字通り体に触れる必要がある。

**何ができる**: 心拍センサーとスマートバンドを同一人物の腕と手首に配置するだけで、電波なしに生体データが流れる。握手の瞬間だけ2者間でデータが転送される「接触認証デバイス」も構成できる。体内植込みペースメーカーとパッチ型リーダーを体表だけで接続すれば、電波が届かない手術室や金属囲み環境でも体内センサーを読み出せる。工場作業者の体表に複数センサーを分散配置し、有線も電波も使わずに全データを1点に集約するBANも実証されている。

**技術の魅力**: 「電波を飛ばさない」ことが傍受対策・干渉対策・消費電力削減のすべてを一度に解決する。BluetoothやNFCは通信圏がボールのように周囲に広がるが、IBCは回路が人体に沿って閉じる——通信が成立している状態が、そのまま「接触が続いている」状態の証明になる。このフィジカルな性質は、ソフトウェア認証では模倣できない。

**本来どこで使われてるか**: 医療ウェアラブルの省電力・省干渉通信として研究が進む。IEEE 802.15.6（WBAN標準）にGCが規定されており、体表センサー間の統一規格として位置付けられている。MIT Media Lab では1996年にThomas Zimmermann がPersonal Area Networkの最初のプロトタイプを発表、握手で名刺データを転送するデモが世界に衝撃を与えた。現在はインスリンポンプ・心臓モニタ・聴覚補助デバイスの連携通信に向けた実装研究が続いている。
出典: https://pubmed.ncbi.nlm.nih.gov/25014932/ / https://pmc.ncbi.nlm.nih.gov/articles/PMC5424740/

### <a id="card-3"></a>🧬 免疫の「自分ではないもの検知」をサイバー侵入検知に移植する 〔move: 異分野の手法移植 / 領域: 生物×セキュリティ〕

**事実**: 胸腺でT細胞が成熟するとき、「自己」のタンパク質と反応するT細胞は殺され、「自己でないもの（異物）」にだけ反応するものが生き残る——これが負の選択（Negative Selection）。1994年、ステファニー・フォレスト（ニューメキシコ大学）がこの仕組みをコンピュータに移植した。「正常な動作パターン（自己）」とマッチしない検出器（detector）をランダムに大量生成し、生成できた検出器が発火したら「異常（非自己）」と判定する。

**何ができる**: 攻撃のシグネチャを一切持たない異常検知器が作れる。ゼロデイ攻撃や未知のマルウェアを「正常から外れている」という理由だけで捕捉できる。訓練データは「正常な状態」だけで足り、ラベル付きの攻撃サンプルが不要。適用対象は「自己」の定義次第で自由に選べる——ネットワークパケットの特徴量でも、システムコールの連番でも、ファイルアクセスパターンでも、「自己」として学習させたいものなら何でも使える。

**技術の魅力**: 異分野移植の妙は「自己と非自己」という2値の枠組みが、どんな正常/異常問題にも直接対応している点だ。免疫系は37億年かけてこの構造を洗練させてきた——つまり「ラベルなしデータで未知の脅威を弾く」という問題設定自体が生物学的に解かれた問題であり、計算機科学がそれを再発見した格好になる。シグネチャベースのIDS（既知の手口しか検出できない）とは原理的に異なる弱点分布を持ち、組み合わせると相互補完になる。

**本来どこで使われてるか**: フォレストのグループは1996年、実際のUnixプロセスのシステムコール列に適用し、バッファオーバーフロー攻撃を99%超の精度で検出する実験を発表した。2000年にHofmeyr & Forrestが発表したARTIS（Artificial immune system for network monitoring）では、分散ノードが免疫細胞のように情報を伝播し合うネットワーク侵入検知システムが構築された。現代のEDR製品に組み込まれる「振る舞い検知」や「ベースライン逸脱検出」は、この思想系譜上にある。
出典: https://link.springer.com/content/pdf/10.1007/978-3-642-59901-9_14.pdf / https://pmc.ncbi.nlm.nih.gov/articles/PMC12534389/
