### <a id="card-1"></a>🆕 世界中の空港が、いまだに1940年代の電報書式で会話している——AFTNという退役できない骨格 〔move: レガシー/廃止予定機能の蘇生 / 領域: ワイルドカード(航空管制・電信史)〕

**事実**: AFTN（Aeronautical Fixed Telecommunication Network）は、第二次大戦期の軍用無線電信をルーツに整備された航空管制用の電文網で、いまも国際民間航空機関（ICAO）加盟国の管制拠点をつないでいる。電文は国際電信アルファベット2号（ITA2/Baudot）時代の制約を今も引きずり、大文字英数字のみ・行頭に固定書式のアドレス（発信局・宛先局コード）を持つテレプリンター形式で書かれる。21世紀になってX.400ベースの後継システムAMHS（ATS Message Handling System）が導入され始めたが、AFTNはそこに完全に置き換わられず、AFTN/AMHSゲートウェイを介して並走している。

**何ができる**: フライトプランやNOTAM（航空情報）は、この骨格に乗せて世界中の管制拠点へ配信される。AMHS未整備の地域や機器故障時には、AFTN側の電文形式へゲートウェイで変換して流せば、送受信システムがどれだけ新旧混在していても最低限の意思疎通が壊れない。つまり「一番古い経路がフォールバックとして生き残る」設計を、更新もせず80年近く運用し続けている。

**技術の魅力**: 普通は古い規格ほど脆く早く葬られる。AFTNが逆に消えないのは、制約が厳しすぎて実装コストが極小だからだ。大文字だけ・固定長ヘッダ・50ボー級の低速度という「削りすぎ」な仕様ゆえに、どんな古い設備でも今日でも実装・保守できる。最新のAMHSより枯れて頑丈な最終防衛線として機能してしまう非対称性が面白い。

**本来どこで使われてるか**: 現在も各国の航空当局がフライトプラン申請・NOTAM配信の正規ルートとして運用しており、ICAOのAMHS移行資料でも「AFTNとAMHSの混在環境をどう共存させるか」が現役の技術課題として扱われている。ナイジェリアなど新興国の空港では、いまもAFTN端末の新規導入・増設が続いている。

### <a id="card-2"></a>🔍 スマホを触るだけで、画面が脈を数えている——タッチパネルが心拍センサーになる静電容量の副作用 〔move: センサーの転用 / 領域: 無線・組み込み・ハードウェア〕

**事実**: 静電容量式タッチパネル（TSP）は、指が触れた位置の電極間の静電容量変化を読んで座標を出す装置だが、指先の実効誘電率は指の中の血流量そのものに引っ張られてわずかに揺れる。心臓が収縮する瞬間（収縮期）と拡張する瞬間（拡張期）で毛細血管の血液量が変わり、それが指先の誘電率の周期変動として、本来は「ノイズ」として無視されているタッチ信号の上に乗っている。

**何ができる**: 電極を横に並べたレイアウト（laterally interspaced electrodes）でこの微小変動を読み、FFTにかけるだけで、手首で数えた実測心拍と一致する心拍数を抽出できることが実証されている。追加のLED・フォトダイオードもカメラも要らず、既存のタッチパネル駆動ICのファームウェアだけで、ゲームやSNSを普通に触っている最中に裏で心拍を拾い続けられる。

**技術の魅力**: タッチパネル設計者が「座標検出の邪魔になるので捨てるべきノイズ」として扱ってきた成分こそが本命のバイタル信号だった、という反転が効いている。光学式の心拍センサーのように専用の発光素子と電力を割く必要がなく、すでに世界中に数十億台配備済みのタッチパネルという“死んだ資産”がそのままバイオセンサーに化ける。

**本来どこで使われてるか**: タッチパネルの静電容量検出は本来、指の位置・タップ・ジェスチャーを判定するためだけの技術で、スマートフォンやタブレットのTSPドライバICが担っている。この心拍抽出手法自体はACMのBody-Centric Computing Systemsワークショップや医用電子工学の論文で報告され、米国特許（US20170112445A1）としても「マルチユース静電容量タッチセンサーによる心拍検出」が出願されている。
出典: https://pmc.ncbi.nlm.nih.gov/articles/PMC7412254/ / https://dl.acm.org/doi/10.1145/3469260.3469667 / https://patents.google.com/patent/US20170112445A1/en

### <a id="card-3"></a>💡 電波を1mmも漏らさず、触れた相手にだけ届く配線——人体そのものを伝送路にするヒューマンボディ通信 〔move: 人間/身体をプロトコルの一部にする / 領域: セキュリティ・認証〕

**事実**: ヒューマンボディコミュニケーション（HBC / IEEE 802.15.6のガルバニック結合方式）は、電磁波を空間に飛ばす代わりに、皮膚に接触させた電極から100kHz〜1MHz帯の微弱な交流電流（振幅0.5〜1mA程度）を体組織そのものに流し、その電流変化で信号を運ぶ通信方式だ。NTTが2005年に発表したRedTactonは同じ発想を電界結合で実装し、体表面を10Mbpsのデータ経路に変えて見せた。信号のほとんどは体組織内に閉じ込められ、空間には実質的に放射されない。

**何ができる**: 受信側も同じ人体に電極を接触させない限り信号を拾えないため、「触れている間だけ」有効な認証チャネルが自然に成立する。ウェアラブル認証リストバンド（Nymi Bandなど）はこの仕組みを使い、装着者の生体信号を鍵として、握手や接触の瞬間だけ他デバイスとの認証を成立させる。BLEやNFCのように離れた場所でパケットを傍受される心配が原理的にない。

**技術の魅力**: セキュリティを暗号強度ではなく物理そのもの（信号が体の外にほぼ存在しない）で担保しているのが効いている。BLEもNFCも「電波を出す」以上は原理的に盗聴の可能性を暗号で塞ぐしかないが、HBCは「そもそも盗聴地点に信号がない」という非対称性を作れる。触れるという最も原始的な身体行為が、そのまま鍵交換プロトコルの物理層になる。

**本来どこで使われてるか**: IEEE 802.15.6はウェアラブル医療機器のボディエリアネットワーク規格として策定され、皮膚に貼ったセンサー間の低電力・低干渉通信に使われている。NTTのRedTactonは名刺交換やドア開錠、ファイル転送のデモとして披露され、現在も医療IoT向けの接触型生体信号伝送（galvanic coupling on-skin biometric transmission）として研究が続いている。
