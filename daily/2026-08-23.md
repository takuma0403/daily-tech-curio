### <a id="card-1"></a>🆕 GPSの届かない場所で、死んだ星の鼓動が座標になる——X線パルサー航法SEXTANT 〔move: 物理現象へのピギーバック / 領域: ワイルドカード(天体物理・航法)〕

**事実**: パルサーは高速自転する中性子星が、灯台のように一定周期でビーム状の電磁波(多くはX線帯)を放つ天体だ。ミリ秒単位で自転するミリ秒パルサーの周期は原子時計に匹敵するほど安定しており、GPSのように「人工衛星が時刻信号を送信する」のではなく、宇宙に元からある天体そのものが極めて正確な"灯台"として使える。NASAゴダードは2017〜2018年、ISS搭載のX線望遠鏡NICER(本来は中性子星内部構造を調べる天文観測機器)を間借りし、SEXTANTという技術実証でこれを検証した。

**何ができる**: SEXTANTは4つのミリ秒パルサーからのX線光子の到達時刻のわずかなズレを52台のX線望遠鏡で測定するだけで、GPS受信機に一切頼らず、8時間の観測でISSの軌道上の位置を約16km(10マイル)以内の精度で自律測位することに成功した。GPSは地球近傍にしか届かないが、パルサーは太陽系のどこから見ても同じ天体現象なので、火星探査機や外惑星探査機が地上局との通信遅延なしに自分の位置を割り出せる、事実上「宇宙のどこでも使える測位網」になる。さらに、GPSは人工信号ゆえにジャミングやなりすましに弱いのに対し、何千光年も離れた天体現象そのものは地球上の誰にも偽造しようがないため、GPSが妨害された非常時のための"偽装不能な時刻・位置の裏付け"としての活用も研究されている。

**技術の魅力**: GPSは「精度」を追求して作られた人工システムだが、パルサー航法は精度で張り合うのではなく「誰にも改竄できない」という別の軸で勝負している。天文観測用の望遠鏡を、装置に一切手を加えず角度を変えるだけで航法装置に転用してしまう、目的の飛躍が効いている。

**本来どこで使われてるか**: NICERは中性子星の質量・半径・内部構造を調べる純粋な天文観測ミッションとしてISSに搭載されており、SEXTANTはそのデータを間借りする形で2018年に世界初のX線パルサー航法の成功を実証した。将来の深宇宙ミッションにおける自律航法手段として、地上局に依存しないバックアップ測位の研究が今も続いている。
出典: https://www.nasa.gov/centers-and-facilities/goddard/nasa-team-first-to-demonstrate-x-ray-navigation-in-space/ / https://www.nasa.gov/directorates/stmd/station-explorer-for-x-ray-timing-and-navigation-sextant/

### <a id="card-2"></a>🔍 指ではなく耳で——静電容量タッチパネルが体の部位を読み取る画像センサーになる 〔move: センサーの転用 / 領域: セキュリティ/認証〕

**事実**: スマホの静電容量式タッチパネルは指先の座標を検出する入力デバイスだと思われがちだが、実体は画面全体に敷き詰められた電極グリッドが、解像度こそ約6dpiと粗いもののタブレット大の面積を持つ"低解像度の画像センサー"だという点が見落とされがちだ。2015年、当時Yahooの研究者だったChristian Holzらは、これをBodyprintという名で実証した——指のタップだけでなく、耳・拳・関節・掌といった体の部位を画面に押し当てたときの静電容量パターンの"形"そのものを、画像として読み取れることを示した。

**何ができる**: 電話に出るときのように耳を画面に押し当てるだけで、専用の指紋センサーを積んでいない端末でもユーザーを本人識別できる。実験では耳による本人認証で精度99.8%、押し当てた体の部位そのものの分類精度99.98%を達成している。指紋センサーのない安価な端末や、ATM・券売機・車載パネルのような「タッチパネルはあるが専用生体センサーがない」機器に、追加ハードウェアを一切足さずに生体認証を後付けできる余地がある。

**技術の魅力**: 「指の1点のタップ座標」しか見ないのが当たり前だったタッチパネルを、面全体の"影絵"として読み解く発想の転換が効いている。低解像度・大面積というタッチパネル特有の中途半端な性能が、指紋のような微細なパターンには不向きな一方で、それよりずっと大きい体の部位のスキャンにはちょうど向いていた、という相性の皮肉が面白い。

**本来どこで使われてるか**: 静電容量タッチパネルは元々、指先のタップ・スワイプ座標を検出するための入力デバイスとして設計されている。BodyprintはACM CHI 2015で発表され、Yahoo Labsの研究として当時大きく報じられた。
出典: https://siplab.org/projects/Bodyprint / https://www.christianholz.net/bodyprint.html / https://thehackernews.com/2015/04/bodyprint-biometric-scanner.html

### <a id="card-3"></a>💡 伝染病の数式が、DBのレプリカを黙って揃える——ゴシッププロトコルという疫学の輸入 〔move: 異分野の手法移植 / 領域: データ/同期/ストレージ〕

**事実**: 1987年、Xerox PARCのAlan Demersらは、複製されたDBサーバー群の内容をどう一致させるかという地味な問題に、中央調整役を置く代わりに疫学(epidemiology)の感染拡大モデルをそのまま輸入して答えた。各サーバーはランダムに選んだ別のサーバーとだけ定期的に情報を交換して食い違いを解消し(anti-entropy)、更新情報を"噂"のように隣へ隣へと伝播させる(rumor mongering)。「更新」を「感染」に、「サーバー」を「個体」に見立てる疫学のアナロジーが、命名だけでなくアルゴリズムの構造そのものに直結している。

**何ができる**: この"ゴシッププロトコル"を使うと、中央のコーディネーターも強い順序保証も前提にせず、ノード数が増えても通信量が緩やかにしか増えない形で、巨大な分散データベースのレプリカを結果整合的に一致させられる。しかも1回に何台へ更新を伝えるかという"fanout"を調整するだけで、感染症の流行制御でいう基本再生産数(R0)や集団免疫閾値と同じ数式で、収束にかかる時間と通信帯域のトレードオフをチューニングできる——つまりDBの同期速度を、感染症モデルのパラメータいじりとして設計できてしまう。

**技術の魅力**: 分散システムの合意やレプリカ同期は本来、厳密な順序保証やロックで解決したくなる問題だが、これを「多少の非効率と多少の遅延を許せば、放っておいても全員に伝わる」という疫学的な緩さで解いてしまう発想の転換が効いている。中央集権的な調整コストをゼロにする代償として、収束の保証を"確率的にほぼ確実"へ格下げしている非対称性も面白い。

**本来どこで使われてるか**: Demersらのオリジナルは、Xerox社内の分散名前解決サービスのレプリカ同期のために設計された。この考え方はAmazon Dynamoのメンバーシップ管理・障害検知にそのまま採用され、Apache Cassandraもクラスタのメンバーシップ把握とレプリカ間データ修復(anti-entropy repair)にゴシップ/エピデミック理論を明示的に引用して使っている。
出典: https://pages.cs.wisc.edu/~swift/classes/cs739-fa14/blog/2014/09/epidemic_algorithms_for_replic.html / https://highscalability.com/gossip-protocol-explained/
