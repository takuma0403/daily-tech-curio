### <a id="card-1"></a>🆕 核実験を聞くための耳が、隕石が世界を2周する音まで拾う——CTBTOインフラサウンド網のロゼット配管フィルタ 〔move: 物理現象へのピギーバック / 領域: ワイルドカード(大気音響学×核不拡散監視)〕

**事実**: 人間の可聴域(20Hz以上)より下の「インフラサウンド」(超低周波音)は大気中でほとんど減衰せず、数千〜数万km先まで伝わる。この性質を使い、包括的核実験禁止条約機関(CTBTO)は世界60カ所に「マイクロバロメーター」という超高感度気圧計を配備した国際監視制度(IMS)を運用し、地下・水中・大気中どこで核実験が起きても生じる微弱な空気振動を捉えようとしている。厄介なのは、この帯域では風そのものが作るノイズの方が信号よりずっと大きいこと。CTBTOはこれを電子フィルタではなく、直径18mにも及ぶ「ロゼット配管アレイ」という完全に機械式のトリックで解決している。地面に放射状に敷いた多数の穴あきパイプの空気圧を1本のマニホールドに集めて平均化するだけで、数m規模でバラバラな風ノイズは打ち消され、数百m離れていても揃って届く本物の信号だけが残る。

**何ができる**: この配管トリックのおかげで、IMSは「核実験1回を聞き逃さない」ためだけの設備のはずが、実質的に地球全体をカバーする無料の超低周波マイクとして機能してしまう。自分のセンサーを1個も持たなくても、世界中に公開されているこの観測データを突き合わせるだけで、大規模な火山噴火や隕石の空中爆発、桁外れの産業爆発まで、発生位置と規模を後から逆算できる。2013年のロシア・チェリャビンスク隕石の空中爆発では、この爆風がIMSの42局中20局に到達し、最も遠い南極の観測点までは伝搬経路にしておよそ87,000km——地球2周分に相当する距離を伝わって記録された。

**技術の魅力**: 核不拡散という極めて閉じた軍事目的のために作られたインフラが、副産物として「誰も打ち上げていない全地球規模のイベント検出網」になってしまう非対称性が効いている。しかも肝心のノイズ除去は電源もソフトウェアも要らない、ただのパイプの配置という物理現象そのもの。デジタル処理が始まるより前の段階で、すでに空気力学がフィルタリングを終えている。

**本来どこで使われてるか**: CTBTOの国際監視制度(IMS)はCTBT(包括的核実験禁止条約)の遵守監視のため、核実験由来のインフラサウンドを検知するのが本来の目的。2013年のチェリャビンスク隕石はネットワーク史上最大の信号として記録され、地球規模の観測性能を証明する事実上の校正イベントになった。
出典: https://www.ctbto.org/our-work/monitoring-technologies/infrasound-monitoring / https://www.ctbto.org/resources/for-the-media/press-releases/russian-fireball-largest-ever-detected-ctbtos-infrasound

### <a id="card-2"></a>🔍 省エネのための"居眠り"が、暗号の秘密を寝言で漏らす——SleepWalkという電源管理サイドチャネル 〔move: サイドチャネル/副作用の利用 / 領域: セキュリティ/認証〕

**事実**: 現代のCPUやマイコンは省電力のため、演算の合間に頻繁に低消費電力のスリープ状態へ入り、必要になった瞬間にまた起きて演算を再開する。この「休む→起きる」の切り替え(コンテキストスイッチ)はレジスタの退避・復元とパイプラインのフラッシュを伴うため、通常の演算より瞬間的に大きな電力スパイクを生む。2025年の研究「SleepWalk」は、楕円曲線暗号ECDSA署名の処理途中でこの居眠り明けのスパイクの"高さ"が、演算対象である秘密のnonce(ノンス)のビットとわずかに相関していることを示した。

**何ができる**: 攻撃者はRaspberry Pi 4のようなありふれたボードにオシロスコープを繋ぎ、トレースの位置合わせも外部トリガーも用意せず、スリープ復帰時のスパイクの振幅だけを拾い集めれば、RustCrypto・BearSSL・GoCryptoなど複数の暗号ライブラリ、ARM・RISC-V双方のアーキテクチャで、ノンスの一部(約20ビット)を復元できてしまう。ノンスはほんの数十ビット漏れるだけで格子攻撃(lattice attack)により秘密鍵全体の復元につながるため、実質的に「定数時間・マスキング済み」を謳う耐タンパー実装の署名処理そのものを、暗号アルゴリズム自体には一切手を出さずに破ることになる。

**技術の魅力**: このサイドチャネルの奇妙なところは、漏れの原因が暗号コードの中身ではなく、その外側にわざわざ足した省エネ機能にあること。定数時間実装やマスキングは「演算そのものの痕跡を消す」ために設計されたが、演算の合間に挟まる電源管理の挙動までは対象にしていなかった。安全に作ったはずの箱の外側、電気代を削るためのつまらない機能の方が、いちばん静かに秘密を漏らしている。

**本来どこで使われてるか**: プロセッサのスリープ/アイドル状態への遷移は、バッテリー駆動のFIDO認証キーやスマートカード、IoT機器を含むあらゆる組み込みプロセッサが標準搭載する省電力機構で、SleepWalkの研究はこの機構がARM Cortex-AやRISC-Vを含む主要アーキテクチャに共通することを実証に利用した。この攻撃が「定数時間・マスキング済み」実装にも有効であることは複数の暗号ライブラリで確認されており、Kaspersky等のセキュリティメディアでも報告されている。
出典: https://arxiv.org/abs/2507.22306 / https://www.kaspersky.com/blog/sleepwalk-side-channel-attack/54083/

### <a id="card-3"></a>💡 衛星はもう聞いていないのに、送信だけは今も義務のまま——121.5MHzホーミングビーコンの第二の人生 〔move: レガシー/廃止予定機能の蘇生 / 領域: 無線/組み込み/ハードウェア〕

**事実**: 航空機や船舶の緊急発信機(ELT/EPIRB)がかつて主力にしていた121.5MHz帯は、1970年代から国際的な衛星捜索救難システムCOSPAS-SARSATの中心周波数だった。しかし実際の遭難信号は50件に1件程度(誤警報率にしておよそ98%)というあまりに多い誤作動と、位置精度の低さから、COSPAS-SARSATは2009年2月1日をもって121.5MHz帯の衛星監視を正式に打ち切り、より高精度な406MHz帯へ完全移行した。ところが米国連邦規則集(47 CFR Part 87)は今も、406MHz帯のELTには「121.500MHzだけで動作するホーミングビーコンを内蔵しなければならない」と明記しており、衛星が聞くのをやめて15年以上経った今もこの周波数は送信され続けている。

**何ができる**: 406MHzの衛星測位はGPS座標付きでもなお100m前後の誤差が残るため、最後の詰めは今も現場の人間と機体がアナログの方向探知機を振り回して音源に近づく"ホーミング"作業に頼っている。つまり121.5MHzは「衛星に聞かせる」役目をとうに終えた後も、世界中の捜索救難隊・空港・ハム無線のフォックスハンティング(方向探知競技)愛好家がすでに使い慣れた受信機と技能を持つ、無料でグローバルな"最終接近インフラ"であり続けている。自分の受信網を1つも持たずとも、この周波数に合わせて発信するだけで、最後の数百mを見つけ出す装備と腕前が世界中にすでに配備されている状態を利用できる。

**技術の魅力**: 一度「衛星からは見えない」と正式に格下げされた周波数が、丸ごと廃止されるのではなく"最後の1マイル専用"という限定的な役目だけを与えられて延命したという、廃止のされ方そのものが面白い。しかも延命の理由は技術的優位ではなく、単に「現場での人間の勘と手作業には、今もこの単純な連続波の方が向いている」という、精度で負けた側が現場対応力で生き残ったという逆転が効いている。

**本来どこで使われてるか**: 米国連邦航空局(FAA)の規則は406MHz ELTに121.5MHzホーミング信号の搭載を義務付けており、COSPAS-SARSAT自身も「121.5MHzの局地捜索用ホーミング信号は衛星フェーズアウトの対象外」と明記している。実際の運用でも、捜索救難隊は406MHzの衛星測位で数百m圏内まで絞り込んだのち、ヘリコプターや徒歩隊が121.5MHzの方向探知機に切り替えて機体・遭難者へ接近する。
出典: https://www.cospas-sarsat.int/en/21-embedded-articles/165-1215-phase-out / https://www.ecfr.gov/current/title-47/chapter-I/subchapter-D/part-87/subpart-F
