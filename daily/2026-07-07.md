### <a id="card-1"></a>🆕 水晶発振子の癖が、消せない指紋になる——TCPタイムスタンプのクロックスキュー 〔move: サイドチャネル/副作用の利用 / 領域: ネットワーク/プロトコル〕

**事実**: RFC 1323 が定義する TCP タイムスタンプオプションは、RTT 計測とシーケンス番号のラップアラウンド対策のためだけに、各パケットへ送信側の内部クロック値を乗せる地味な拡張にすぎない。だがこの値が増えていくペースは、各端末の水晶発振子の製造誤差(ppm 単位のズレ = クロックスキュー)にそのまま依存する。2005年、Kohno・Broido・claffy の論文はこの増分パターンから発振子の個体差を線形回帰で抽出し、それを物理端末の指紋として使えることを示した。

**何ができる**: 1時間あたり2000パケット程度観測するだけで6ビット以上のエントロピー(100万台に1台を区別できる精度)でクロックスキューを推定できる。この値は NAT を越えても、IP アドレスが変わっても、NTP でシステム時刻を合わせ直しても変化しないため、「同じ物理端末が別 IP・別ネットワークから接続してきた」ことを Cookie も TLS フィンガープリントも使わず、パケットヘッダの数値だけから検出できる。

**技術の魅力**: 普通の追跡対策はソフトウェア層(Cookie・IP・UA文字列)を消せば無効化できるが、この指紋は水晶発振子という物理部品の製造ばらつきに由来するため、OS を入れ替えても VPN で IP を変えても NTP で時刻を合わせても消えない。「ソフトウェアは騙せてもハードウェアの癖は騙せない」という非対称性が、そのまま追跡にも端末認証にも転用できる。

**本来どこで使われてるか**: 元々は TCP の往復遅延計測とシーケンス番号ラップアラウンド対策という、性能改善のための地味な拡張(RFC 1323)。ネットワークフォレンジックの文脈では、スプーフィングされたパケットの送信元特定や、同一の物理サーバーが複数のホスト名を装っていないかの検出に応用される。同じ原理は、物理マシンと仮想マシンでクロックのノイズ特性が異なることを利用した、マルウェア解析用サンドボックス(VM)の検知手法にも派生している。
出典: https://www.caida.org/catalog/papers/2005_fingerprinting/KohnoBroidoClaffy05-devicefingerprinting.pdf / https://www.theregister.com/2005/03/11/clock_skews_finger_pcs/

### <a id="card-2"></a>🔍 宇宙から降ってくる音を、1958年のままの方式で拾う——ISSのSSTV 〔move: レガシー/廃止予定機能の蘇生 / 領域: 無線・組み込み・ハードウェア〕

**事実**: SSTV(Slow-Scan Television)は1958年に Copthorne Macdonald が考案した、音声帯域(約3kHz)しか使えないアマチュア無線の回線越しに静止画を送る方式。輝度の高低をそのまま音の周波数の高低(FM)に変換し、1画面を数十秒〜数分かけて上から順に走査して音として送る。動画もデジタル化もない、テレビ規格としてはとうに時代遅れの技術だが、たった一つの理由でずっと生きながらえている。

**何ができる**: 国際宇宙ステーション(ISS)のロシアサービスモジュールにあるアマチュア無線局(コールサイン RS0ISS)は、年に数回程度のARISSイベントで、145.800MHz FM から PD120 モードの SSTV 画像をおよそ2分オン・2分オフで送り続けている。地上側は20ドル程度のハンディ無線機や RTL-SDR ドングルと、スマホのマイクにその音を聞かせるだけの無料アプリ(Robot36 など)さえあれば、免許なしに「今まさに宇宙から降ってきた画像」を自分の手元でデコードできる。

**技術の魅力**: パケット無線も TCP/IP も要らず、「音声さえ通ればどんな回線でも画像が送れる」という設計そのものが強み。デジタル通信は帯域確保や誤り訂正のためにプロトコルスタックを積み上げるが、SSTV は1958年当時のまま「輝度=周波数」という単純さだけで、電離層越しの雑音だらけの電波にも耐える。サーバーもインターネットも衛星回線契約も要らず、必要なのはアンテナと耳(マイク)だけという、究極の「サーバー不要」を70年近く体現し続けている。

**本来どこで使われてるか**: 元は1958年、声しか送れない狭帯域回線で写真を送りたいという動機で生まれたアマチュア無線の趣味の技術。今は ARISS(Amateur Radio on the International Space Station)が教育普及イベントとして定期開催し、世界中の学校や個人が受信画像を専用ギャラリーに投稿して記念証をもらえる仕組みまである。QO-100 や FUNcube など他の衛星も、テレメトリ画像の配信にこの古い方式を流用している。
出典: https://amsat-uk.org/beginners/iss-sstv/ / https://en.wikipedia.org/wiki/Slow-scan_television / https://www.ariss.org/upcoming-sstv-events.html

### <a id="card-3"></a>💡 星座を探す数式が、鼻歌の代わりに曲を当てる——ShazamとAstrometryの幾何学的ハッシング 〔move: 異分野の手法移植 / 領域: AI・メディア処理〕

**事実**: 望遠鏡で撮った星野写真から「これがどの空の場所を撮ったものか」を自動特定する技術(プレートソルビング)と、雑音だらけのバー内の数秒間の録音から「今流れている曲」を言い当てる Shazam は、一見まったく無関係な分野に見える。だが両者は同じ「幾何学的ハッシング(geometric hashing)」——1988年に Lamdan と Wolfson がコンピュータビジョンの物体認識のために考案した手法——を、互いに知らないまま独立に転用している。

**何ができる**: どちらも、データを疎な2次元の点群(星の座標、あるいは音声スペクトログラムの周波数ピークが作る「コンステレーションマップ」)に落とし込み、その中の小さな点の組(4〜5点1組の"アステリズム"や、ピークの2点ペア)ごとに回転・拡大縮小に依存しない不変量を計算してハッシュ化し、事前に索引化した巨大な DB(星表、または何百万曲分の指紋 DB)と高速照合する。この設計のおかげで、Astrometry.net はメタデータが一切ない星野写真から数秒で撮影方向を特定し、Shazam は雑音混じりの数秒の録音から数百万曲の DB を1曲まで絞り込める。

**技術の魅力**: 「大量のノイズに埋もれた小さな幾何学的パターンを、力任せの総当たりなしに見つける」という同一の数学問題が、天文学と音楽識別という接点のない2分野にそれぞれ独立に着地した点が面白い。コンピュータビジョン発の抽象的な手法が、望遠鏡の座標系にも、音のスペクトログラムという別種の「点群」にもそのまま刺さるという汎用性の高さが、非対称的な強みになっている。

**本来どこで使われてるか**: 幾何学的ハッシングは元々1988年、姿勢や縮尺が未知の物体をモデル DB と照合するコンピュータビジョンの物体認識手法として提案された。天文学では Astrometry.net がこれを使い、GPS もメタデータもない任意の望遠鏡画像を数秒で座標系(WCS)付きにする「ブラインド較正」を実現している。音楽分野では2003年に Avery Wang がこれをスペクトログラムのピーク照合に応用した論文を発表し、それが今も Shazam や Apple Music の曲識別エンジンの核として動いている。
出典: https://arxiv.org/pdf/0910.2233 / https://www.ee.columbia.edu/~dpwe/papers/Wang03-shazam.pdf / https://researchrepository.wvu.edu/cgi/viewcontent.cgi?article=6704&context=etd
