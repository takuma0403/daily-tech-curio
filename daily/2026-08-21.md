### <a id="card-1"></a>🆕 たった1個の排他ロックが、サーバーレスの本物のファイルシステムを生む——OPFSの同期アクセスハンドル 〔move: 制約の極端化 / 領域: データ/同期/ストレージ〕

**事実**: OPFS(Origin Private File System)は File System Access API の一部で、通常のファイルAPIのようにユーザーへ許可ダイアログを出すことなく、オリジンごとに専用のプライベートなファイルツリーをブラウザ内部に持てる。ここで各エントリに対して `createSyncAccessHandle()` を呼ぶと、そのファイルへの「排他ロック」を握った同期I/Oハンドルが得られる。ロックを握っている間、他のワーカーやタブは同じファイルへの `createSyncAccessHandle()` も `createWritable()` も一切できない——1ファイルにつき同時に触れるのは1実行文脈だけという極端な制約であり、しかもこの同期I/Oが許されるのはDedicated Workerの中だけ、メインスレッドでは使えない設計になっている。

**何ができる**: 本来はSQLite WASM(sqlite-wasm)がPOSIXのread/write/fsyncをそのままOPFSにマッピングし、本物のファイルI/Oをブラウザタブの中だけで完結させるための仕組みだが、「1ファイル=1排他ロック」という制約自体を流用すると、サーバーもIndexedDBも使わずタブ間の分散ロック(ミューテックス)がファイルの取得成否だけで組める。専用のWeb Locks APIが既にあるのに、あえてこちらを使う旨みは、ロックの所有者(タブ/ワーカー)が死んだ瞬間にハンドルごと自動解放される保証が強いことと、ロックそのものに任意サイズのバイナリを同期的に読み書きできること——ロックと共有状態のストレージが1つのプリミティブに同居し、ネットワーク越しの調停役なしでオフラインのまま完結する。

**技術の魅力**: 排他制御のための専用APIを別に立てず、「ファイルを開けたかどうか」自体をロックの成否シグナルへ転用しているのが効いている。しかも同期I/Oというブラウザが本来嫌う操作を、Workerという檻の中に閉じ込めることで安全に許可した、という設計そのものが「制約を極端にすることで安全と速度を両立させる」典型例になっている。

**本来どこで使われてるか**: sqlite-wasmが公式にOPFS VFS(`opfs-sahpool`など)としてこれを使い、Cライブラリのpread/pwrite/fsyncをそのままFileSystemSyncAccessHandleのread/write/flushへ橋渡ししている。PowerSyncやSQLite公式フォーラムでも、Safari/Firefoxでの対応状況込みでブラウザ内蔵DBの永続化層として運用実績が積まれている。
出典: https://developer.chrome.com/blog/sqlite-wasm-in-the-browser-backed-by-the-origin-private-file-system / https://developer.mozilla.org/en-US/docs/Web/API/FileSystemSyncAccessHandle / https://powersync.com/blog/sqlite-persistence-on-the-web

### <a id="card-2"></a>🔍 学習ゼロの"耳"——数式で固定したCNNが音の識別を肩代わりする、散乱変換 〔move: 異分野の手法移植 / 領域: AI/メディア処理〕

**事実**: Wavelet Scattering Transform(散乱変換)は、フランスの数学者Stéphane Mallatが定式化した信号表現で、構造だけ見ると畳み込みニューラルネットそのもの——ウェーブレットフィルタバンクで畳み込み、絶対値(モジュラス)を取り、また畳み込む、という層を何段も重ねる。決定的に違うのは、そのフィルタが一切学習されない点。ウェーブレットの形を調和解析の理論側から固定して決めてしまうので、勾配降下も、ラベル付きデータも、GPUでの長時間学習も要らない。CNNの"形"だけを、学習という中身抜きで持ち込んだような代物。

**何ができる**: このおかげで、教師データがほとんど無い・計算資源が乏しい環境でも、時間・周波数のずれや音量変化に頑健な特徴量が最初から手に入る。実際、低リソースな言語識別(Spoken Language Identification)では、学習データが少ない条件で散乱変換ベースの特徴が通常の学習型フロントエンドより汎化性能で上回ると報告されている。音響シーン分類や虹彩認証など、「畳み込みの形」だけを再利用して別ドメインの分類器へ挿げ替える、という使い方が繰り返し行われている。

**技術の魅力**: 「学習して重みを見つける」のがニューラルネットの本質のはずなのに、その重みを理論から天下り的に固定してしまっても、ある程度は同等の表現力を持つ——という非対称性が面白い。畳み込みという計算の"型"と学習という中身を切り離せることを、遠く離れた分野(調和解析・不変量理論)の道具立てで証明してみせた、発想の輸入劇でもある。

**本来どこで使われてるか**: 元々はMallatが画像のテクスチャ分類のために提案した、時間・周波数の微小なシフトや変形に不変な特徴抽出理論。そこからKymatioという実装ライブラリを介して、低リソース音声言語識別・音響シーン分類・虹彩認証など、まったく別ドメインの分類問題へ横展開されている。
出典: https://arxiv.org/html/2310.00602 / https://arxiv.org/pdf/1812.11214 / https://arxiv.org/pdf/1507.02177

### <a id="card-3"></a>💡 舌が、暗闇のセンサー映像を受信する画面になる——BrainPortという電気触覚バス 〔move: 人間/身体をプロトコルの一部にする / 領域: ワイルドカード(感覚代替工学)〕

**事実**: BrainPortは舌の上に約400個の電極を並べたパッド(通称"ロリポップ")を当て、カメラが撮った映像を電気刺激のパターンとして舌に流し込む感覚代替(sensory substitution)デバイス。舌は触覚受容器の密度が指先並みに高く、大脳の体性感覚野での占有面積(いわゆるホムンクルス)も大きいため、電気刺激の"模様"を訓練すると徐々に「舌で感じている」という自覚が薄れ、頭の中で空間的な表象として知覚され始める——おおむね15時間ほどの訓練でその切り替えが起きるとされる。

**何ができる**: BrainPort V100は視覚障害者向けにFDA承認を得ており、光の検知・簡単な物体の識別・動きの検出ができる。だが肝は「入力は可視光カメラでなければならない」という制約がどこにも無いこと。赤外線・暗視カメラを繋げば、視覚を一切経由せず舌へ直接"暗闇の映像"を流し込める。実際、赤外線センサーを兵士のヘルメットに載せて舌へ360度分の暗視情報を送る研究や、ソナー信号を舌インターフェースへ通して潜水士が濁った暗い水中で"見る"実験まで行われてきた。網膜という遅延源を丸ごとバイパスできる点も利点として挙げられている。

**技術の魅力**: 「目で見る」を「舌で感じる」へ単純に置き換えるのではなく、そもそも脳は入力がどの神経経路から来たかを気にせず、パターンさえ一貫していれば新しい"感覚"として学習してしまう——という脳の可塑性そのものを土台にしている。センサーの種類を選ばない汎用の電気触覚バスとして体の一部(舌)を使う点が、「プロトコルとしての人体」という発想をそのまま体現している。

**本来どこで使われてるか**: 臨床では失明者の視覚代替(BrainPort V100/V200)や平衡感覚障害のリハビリ(前庭代替)に使われている。軍事・潜水の実験文脈では、赤外線暗視カメラやソナーの生データをそのまま舌に流し込み、可視光を経由しない"別チャンネルの知覚"を作る用途にも転用されてきた。
