### <a id="card-1"></a>🆕 逆戻りできない数字が、パスコード総当たりの門番になる——モノトニックカウンタの転用 〔move: 仕様の目的外利用 / 領域: セキュリティ/認証〕

**事実**: TPMやIntel SGX、Appleのセキュアエンクレーブが持つ「モノトニックカウンタ」は、値が絶対に減らず、外部から任意の値に書き換えることもできないハードウェアカウンタ。本来はDRMやライセンス管理の世界で「巻き戻し攻撃」を防ぐために作られた——VMのスナップショットを昔の状態に戻したり、システムクロックを過去に巻き戻したりして、期限切れのライセンスや使用回数の残りを不正に復活させる手口を封じるための地味な部品で、NVRAM摩耗対策で数秒に1回程度しか増分できないよう意図的にレート制限されている。

**何ができる**: この「二度と後戻りしない」性質を、ライセンスではなくパスコードの試行回数を刻む用途に転用できる。Appleのセキュアエンクレーブはパスコードを1回間違えるたびにこのカウンタを進め、値に応じて次の入力までの待ち時間を指数関数的に伸ばす。ストレージを丸ごと吸い出してオフラインで総当たりしても、カウンタごとハードウェアを騙さない限り遅延はリセットされない。Signalのバックアップ復元(Secure Value Recovery)も同じ発想で、サーバーは平文PINを一切知らないままSGXエンクレーブの中だけで試行回数を数え、上限を超えると鍵ごと自壊させる。

**技術の魅力**: 本来は「時計を巻き戻すな」という受け身の整合性チェックの道具を、「何回叩かれたか」を数えて能動的にブレーキをかけるレートリミッタへ横流ししているのが効いている。ソフトウェアのカウンタなら電源断や仮想化のスナップショット巻き戻しで簡単にゼロへ戻せてしまうが、モノトニックカウンタは「前に進むことしかできない」という一点だけをハードウェアで保証する。2016年、FBIがSan Bernardino銃撃事件の容疑者のiPhone 5cのロック解除をAppleに求めた際も、まさにこの遅延機構を無効化するファームウェアの作成を要求し、拒否されたことが一大訴訟に発展した。

**本来どこで使われてるか**: 元々はTPMやIntel SGXのSealed Storageで、ゲームのセーブデータやDRMライセンスの残り回数を巻き戻し攻撃から守るための機構。SignalのSecure Value RecoveryはこれをSGXベースのRaftクラスタ上に構築してPIN試行回数の門番にし、AppleはiPhoneのSecure Enclaveでパスコード遅延の実装に使っている。
出典: https://signal.miraheze.org/wiki/Secure_Value_Recovery / https://en.wikipedia.org/wiki/FBI%E2%80%93Apple_encryption_dispute

### <a id="card-2"></a>🔍 自分は一切喋らず、他人の電波のこだまだけで空を見張る——パッシブレーダー 〔move: 物理現象へのピギーバック / 領域: ネットワーク/プロトコル〕

**事実**: 普通のレーダーは自分で電波を発射し、跳ね返りの時間差から距離を測る。だがpassive radar(Passive Coherent Location, PCL)は一切送信せず、すでに空を飛び交っているFMラジオ・DVB-T地上デジタル放送・GSM携帯基地局の電波を「借りて」使う。アンテナを2系統用意し、一方で放送局からの直接波、もう一方で対象物に当たって跳ね返ってきた反射波を受け、両者のドップラーシフトと遅延の相関だけから位置と速度を割り出す。

**何ができる**: 自前の送信機を持たないので発する電波はゼロ。電子戦の脅威警報受信機(RWR)に探知されず、妨害の的にもならず、新たな周波数割り当ても不要な「聴くだけ」の監視網が作れる。既存の放送インフラが密集する都市部ほど有利で、低空を這う巡航ミサイルやドローンのようにアクティブレーダーが苦手とする低高度目標も、地表近くまで届くFM/TV波なら拾いやすい。Lockheed MartinのSilent Sentryはまさにこの発想でFM放送とアナログテレビ波を"照明"に使い、Roke Manor/BAE SystemsのCELLDARはGSM基地局の電波だけで60km先の航空目標を追跡した。

**技術の魅力**: 「自分は一言も発さず、他人の声のこだまだけを盗み聴く」という受動的な発想が、パルスを撃って反射を待つレーダーの常識を裏返している。放送局はすでに高出力・広帯域の電波を四六時中垂れ流しているので、専用レーダーを新設するコストがまるごと浮く——公共インフラの"ついで"に軍事監視網が寄生する非対称性が肝。

**本来どこで使われてるか**: FMラジオやDVB-T放送は言うまでもなく音楽・映像を家庭に届けるためのもの。Passive radarはこの放送波を横から拾い読みするだけで、Lockheed MartinのSilent Sentry(1998年発表)やRoke ManorのCELLDAR、各国の防空研究機関が実用化・研究を進めている。
出典: https://aviationweek.com/silent-sentry-new-type-radar / https://www.electronicsweekly.com/news/archived/resources-archived/roke-manor-research-uses-mobile-phone-signals-to-make-cheap-2002-07/

### <a id="card-3"></a>💡 光る豆電球が、光を聴く耳にもなる——LEDの二重生活 〔move: センサーの転用 / 領域: 無線/組み込み/ハードウェア〕

**事実**: LED(発光ダイオード)は光を出すための部品だが、そのPN接合は太陽電池と原理的に同じもの。逆バイアスをかけたまま放っておくと、当たった光の量に比例した微弱な光電流が流れる——つまりLEDは「タダで手に入るフォトダイオード」でもある。この性質自体は昔から知られていたが、電子工作の大家Forrest Mimsが専用の受光素子なしの計測にLEDを使い倒したことで広く知られるようになった。

**何ができる**: 専用のフォトダイオードを1個も追加せずに、基板にすでに載っている表示・インジケータ用のLEDを一瞬だけ受光モードに切り替え、周囲の明るさや他のLEDの点滅を読み取れる。これを敷き詰めれば、三菱電機研究所(MERL)が2003年に発表した「自分の光を自分で見る」双方向LEDのように、表示パネルそのものが粗いカメラにもなり、近づいた指や物の影を検知できる。同じ原理でDisney Researchは2012年、LED同士が発光と受光を高速に切り替えることで専用の送受信回路なしにLED-to-LEDの可視光通信網を組み、触れ合わせるだけで玩具同士が信号をやり取りするデモを発表した。

**技術の魅力**: 「発光素子」と「受光素子」を別部品として扱うのが当たり前の設計だが、実は同じ半導体接合が両方をこなせるという対称性を突いている。部品点数を1つも増やさずにセンサーが"タダで"手に入る非対称なコスト構造が効いていて、切り替えはピンの電気的な向きを反転させるだけでいい——ソフトウェア側は「同じピンで発光と受光を高速に交互させる」だけで済む。

**本来どこで使われてるか**: LEDはもちろん表示・照明が本来の役目。だがこの受光特性は、コスト最優先の玩具や家電で「表示のついでにセンサーとしても使う」低価格設計や、MERLの自己感知ディスプレイ研究、Disney ResearchのEnLighting(玩具向け可視光通信)など、専用フォトダイオードを省くための研究・実用の両方で使われている。
出典: https://hackaday.com/2015/10/13/citizenscience/ / https://la.disneyresearch.com/publication/led-to-led-visible-light-communication-networks/
