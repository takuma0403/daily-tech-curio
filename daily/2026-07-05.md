### <a id="card-1"></a>🆕 振動モーターの逆起電力が耳になる——VibraPhone 〔move: センサーの転用 / 領域: 無線/組み込み/ハードウェア〕

**事実**: スマホの振動モーター(ERMやLRAなどのハプティクス用アクチュエータ)は本来「電圧をかけると振動する」出力専用の部品だが、内部のコイルと磁石の関係はスピーカーと同じで可逆的だ。外部から機械的な振動(=空気中の音)が加わると、コイルには逆方向の微弱な誘導電圧(逆起電力/back-EMF)が発生する——出力装置がそのまま入力装置になる。マイクと違いOSはこの配線の電圧読み取りに権限確認をまったく要求してこない。2016年、メリーランド大学のNirupam RoyとRomit Roy ChoudhuryがMobiSysで"VibraPhone"として実証した。

**何ができる**: 振動モーターの2本の配線の逆起電力を読み取り続けるだけで、周囲の空気振動の低帯域成分を拾える。信号自体は人の声の帯域より狭く雑音混じりだが、「人の発話には音響文法がある」という前提でスペクトル減算・フォルマント外挿・倍音再構成といった音声特有の復元処理をかけると、人間が聞き取れる単語列として80%超の精度で再構成できる。マイク権限を一切要求しないアプリが、振動モーターの配線を読むだけで、ネットにもクラウドにも頼らずその場で会話を復元できてしまう。

**技術の魅力**: 「出力専用」という設計上の役割分担は、電磁誘導コイルという物理部品のレベルではそもそも意味を持たない。設計者は"モーター"と"マイク"を別カテゴリの部品として権限モデルを組んだが、Gyrophone/Spearphoneがセンサー(角速度計・加速度計)の共振を悪用したのとは逆に、こちらはアクチュエータ(出力装置)を回路レベルで反転させて入力装置に変える。出力を逆再生して入力にする、という発想の逆転が効いている。

**本来どこで使われてるか**: 振動モーターは着信通知・タッチ操作のハプティックフィードバック・ゲームコントローラの振動演出のために、あらゆるスマホ・ウェアラブルに搭載されている純然たる出力デバイス。研究チームはこの逆起電力読み取りが音声認識ウェアラブルの補助マイクやMIMOマイクの副チャンネルとしても使える一方、マルウェアによる盗聴経路になり得ることも警告した。
出典: https://www.cs.umd.edu/~nirupam/images/2_publication/papers/VibraPhone_MobiSys16_nirupam.pdf / https://dl.acm.org/doi/10.1145/2906388.2906415

### <a id="card-2"></a>🔍 一度捨てた電波航法を"GPSが死んだ日"のために生き返らせる——eLoran 〔move: レガシー/廃止予定機能の蘇生 / 領域: ワイルドカード〕

**事実**: LORAN-Cは1950年代からの地上局ベースの長距離電波航法システムで、複数の送信局から届く超長波(100kHz)パルスの到達時刻差から自機位置を割り出す仕組みだった。GPSの精度と利便性に押され、米国・カナダは2010年に、日本や欧州各国もそれに続いて2010年代半ばまでにLORAN-Cを次々と廃止し、送信塔は解体または放置された。ところがGPSは民生用の微弱な電波であるがゆえにジャミングやなりすまし(スプーフィング)、太陽フレアに極めて脆弱で、単一の測位システムに社会インフラ全体が依存するリスクが近年顕在化している。

**何ができる**: eLoranは廃止されたLORAN-Cの送信インフラと超長波パルスの仕組みを土台に、パルスの位相まで利用することで単一測位点で数メートル級の精度、GPSに匹敵するナノ秒級の時刻・周波数基準を、衛星なしの地上波だけで提供し直す。GPS衛星とは周波数帯も伝搬経路(地表波)も送信元設備もまったく別系統のため、GPSを狙うジャマーやスプーファーが同時にeLoranまで妨害するのは原理的に難しい。GPSが丸ごと止まる有事に、金融取引のタイムスタンプ基準や船舶・航空機の航法をオフラインの地上インフラだけで代替できる。

**技術の魅力**: 一度「時代遅れ」と判定されて解体された巨大な地上インフラを、"GPSという単一障害点への依存"という後から発覚したリスクのためだけに、実質的に息を吹き返らせようとしている。技術的に古いものが劣っているとは限らず、"GPSと違う原理・違う周波数・違う設備で壊れる"という一点にこそ価値が生まれた——優劣ではなく多様性のために廃止技術を蘇生させる発想が新しい。

**本来どこで使われてるか**: 米国政府は2008年・2015年と2度eLoran構築の意向を表明し、2017年のNational Timing Resilience and Security ActでもGPSバックアップとしての復活が提案されたが、予算の壁で本格実現は遅れ続けている。英国では2014年にGeneral Lighthouse Authoritiesが商船向けeLoran実証局(アンソープ局など)を稼働させたが、その後の予算削減でパイロット計画は停滞した。韓国は独自にeLoran整備を進めるなど、GNSS代替のPNT(測位・航法・時刻)インフラとして各国で検討が続いている。
出典: https://www.gpsworld.com/eloran-part-of-the-solution-to-gnss-vulnerability/ / https://en.wikipedia.org/wiki/Loran-C

### <a id="card-3"></a>💡 「全部送る」をやめて差分だけに切り詰める——Erlayの集合スケッチ 〔move: 制約の極端化 / 領域: データ/同期/ストレージ〕

**事実**: Bitcoinのノードは新しいトランザクションを受け取るたびに、直接つながる全ピアへその内容を転送(フラッディング)してネットワーク全体に伝播させる。ノード数や接続数が増えるほど同じトランザクションが何重にも再送され、帯域が接続数に比例して膨らむ。2019年にNaumenkoらが提案したErlayは、この「全部を全員に送る」という前提そのものを疑い、PinSketch(誤り訂正符号ベースの集合スケッチ)を実装したMinisketchライブラリを使って、ノード同士が持つトランザクション集合の"差分だけ"を求める通信に置き換えた。

**何ができる**: 各ノードは自分の持つトランザクション集合を固定サイズのスケッチ(整数の組の集合)へ圧縮してピアに送る。受け取った側は自分のスケッチとの差分演算だけで「相手にあって自分にない/自分にあって相手にない」トランザクションのIDを直接復元でき、双方が一致している分は一切送受信しない。差分がd件なら通信量もほぼd件分に収まる仕組みで、論文はこの方式でBitcoinネットワーク全体の帯域消費を現状の接続数で約40%削減でき、接続数が増えても帯域がほぼ一定に保たれると報告している。

**技術の魅力**: 同期というと「持っているデータをまず全部送り合う」のが素朴な発想だが、Erlay/PinSketchは「相手が何を持っているかは事前に分からなくていい、差分の"個数"さえ小さければ、その中身だけを復元できればいい」という制約に振り切っている。集合全体ではなく差分の情報量にまで通信コストを切り詰める極端な最小主義が、P2Pネットワークの帯域という物理的制約を正面から解いた。

**本来どこで使われてるか**: PinSketchはもともと生体認証のファジー抽出器(指紋データの誤り訂正)向けに考案された符号理論の道具だったが、Bitcoin CoreはこれをMinisketchというC++ライブラリとして実装し、2021年のバージョン0.21以降でErlayの前段としてトランザクション伝播の帯域最適化に採用している。同種の集合差分アルゴリズムは分散データベースのレプリカ同期やディレクトリ同期にも応用が進んでいる。
出典: https://arxiv.org/abs/1905.10518 / https://people.ece.ubc.ca/sasha/papers/ccs19.pdf
