### <a id="card-1"></a>🔁 Spectre に殺されたブラウザ共有メモリ、ヘッダ2行で蘇生した 〔move: レガシー/廃止予定機能の蘇生 / 領域: AI/メディア処理 / レンズ: 5分で動くデモにできる〕

**事実**: `SharedArrayBuffer` は2017年末にブラウザへ実装され、JS ワーカー間で真の共有メモリ（コピーなし）を使えるようにした。しかし2018年1月、Spectre 脆弱性の開示を受けてすべての主要ブラウザが一斉に無効化した。高精度の `performance.now()` タイマーとして悪用され、投機的実行でメモリを読み出せてしまうという理由で。その後、Cross-Origin Isolation（COOP + COEP の2ヘッダ）という OS レベルのプロセス分離を条件に、Chrome 92（2021年7月）で復活した。同じ API が、別のアーキテクチャ判断で再有効化された珍しいケース。

**何ができる**: `Cross-Origin-Opener-Policy: same-origin` と `Cross-Origin-Embedder-Policy: require-corp` の2行を配信サーバーのレスポンスヘッダに加えるだけで、`SharedArrayBuffer` が使えるようになる。これはゼロコピー共有メモリなので、カメラフレームを ML モデルに渡す際に ArrayBuffer を丸ごとコピーする必要がなくなる。TensorFlow.js の WASM バックエンドや ONNX Runtime Web、Pyodide（ブラウザ内 Python）はこれを前提に設計されており、大きな行列データをワーカー間でコピーなしに渡してリアルタイム推論の遅延を削れる。

**技術の魅力**: 「廃止されたら戻らない」が普通だが、ここでは「同じ機能を別の安全モデルで再定義して返ってきた」。制限の変え方も面白い——タイマー精度を落とすのではなく、OS のプロセス境界で Spectre の前提（共有メモリ読み出し）を壊した。2ヘッダを追加すると自分のページに iframe で外部コンテンツを混在させられなくなる副作用があり、広告まみれのサイトには適用できないという現実の摩擦も残っている。「セキュリティと利便性のトレードオフを、制度（ヘッダ）として可視化する」構造が効いている。

**本来どこで使われてるか**: ブラウザのマルチスレッド ML とWebAssembly 実行環境が主戦場。TensorFlow.js は SharedArrayBuffer が使えると GPU→CPU コピーを削減し、Pyodide は Python の `multiprocessing` 相当をワーカー間共有メモリで模倣する。音声処理では `AudioWorklet` とメインスレッドで同一バッファを共有し、低遅延パイプラインを実現する。Web ゲームでは物理演算ワーカーと描画ワーカーが同じシーングラフを触る用途にも使われている。
出典: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/SharedArrayBuffer / https://web.dev/articles/coop-coep

### <a id="card-2"></a>🔐 TLSでまだ平文だった宛先ドメインを最後に暗号化する ECH 〔move: 制約の極端化 / 領域: セキュリティ/認証〕

**事実**: HTTPS は通信内容を暗号化するが、TLS 1.3 のハンドシェイクでも「どのドメインに接続しようとしているか」を示す SNI（Server Name Indication）フィールドは平文で流れていた。同一サーバーが複数ドメインを束ねる（Virtual Host）際に、どの証明書を出すか決めるために SNI が必要だったからだ。ISP・ファイアウォール・検閲機関はこれを読んでドメイン単位でブロックしてきた。ECH（Encrypted Client Hello）はSNIを含む ClientHello の中身を、DNS の HTTPS リソースレコードに公開されたサーバー公開鍵で暗号化する。外から見えるのは「Cloudflare のような中継ホストに接続した」という事実だけになる。

**何ができる**: 制約を極端化して「外のネットワークには接続先ドメインを一切明かさない」という要件を考えると、ECH + Oblivious DNS over HTTPS（ODoH）の組み合わせがほぼそれを満たす。ECH で TLS ハンドシェイクの SNI が隠れ、ODoH で DNS クエリも匿名化される（DoH プロキシがどのクエリを誰が出したか紐付けできない構造）。Cloudflare が2023年に ECH を本番デプロイし、Firefox 117（2023年）でデフォルト有効化、Chrome 117（2023年）で試験的有効化された。現時点で Cloudflare 上の数億ドメインが ECH 対応済みになっている。

**技術の魅力**: 鶏と卵問題があった——暗号化するには公開鍵が必要だが、その鍵をどう事前に伝えるか。解決策が「DNS の HTTPS レコードに公開鍵を載せる」というシンプルさ。しかし DNS が見えるとドメインがバレるので、DNS もEncrypted DNS（DoH/DoT）で隠す必要がある。制約の連鎖が積み上がって、とうとう TLS ハンドシェイクから最後の平文フィールドが消えた。SNI 暗号化の前身 ESNI が2018年に設計されて実装に問題があり廃止、仕切り直しで ECH として2022年以降に実用化されたという曲折もある。

**本来どこで使われてるか**: 検閲回避とプライバシー保護が主目的。TLS でパケットをインスペクションするコーポレートファイアウォールやDPI（Deep Packet Inspection）機器はドメインリストでブロックを行うが、ECH がデフォルト有効になるとそのブロック戦略が根本的に機能しなくなる。そのためインターネット検閲の強い国では ECH 自体をブロックする動きも出ている（ECH のフォールバックを無効化すると接続が失敗するので事実上ブロックできる）。IETF では draft-ietf-tls-esni として標準化が進行中。
出典: https://blog.cloudflare.com/encrypted-client-hello/ / https://blog.mozilla.org/security/2023/10/18/firefox-117-encrypted-client-hello/

### <a id="card-3"></a>📡 他人のWiFi電波を鏡にして電池ゼロで通信する 〔move: 物理現象へのピギーバック / 領域: 無線/組み込み〕

**事実**: アンビエントバックスキャッタ（Ambient Backscatter）は、周囲に飛び交う WiFi（802.11）の電波を電源と搬送波の両方に使い、電池も能動的な送信回路も持たずに通信するタグの技術。タグはアンテナのインピーダンスを高速に切り替えることで、入射した WiFi フレームを「吸収（0）」か「反射（1）」に変調する——これがバックスキャッタ。受信側はその反射パターンの変化を読んでタグが何を送ったか復元する。従来の RFID と違い、専用の読み取り機やキャリア発振器が要らず、周囲の WiFi ルーターをそのまま借用する。

**何ができる**: 電池ゼロかつ単純な半導体回路とアンテナだけで、室内で数十Kbps〜数Mbps のデータ転送が可能になる。温度センサー・在庫タグ・スマートパッケージに貼り付けて、WiFi インフラが既にある場所ならどこでも動く。2020年代以降の研究では、変調を洗練させることで通常のスマートフォン（特別なハードなし）が受信側になれるバリアントも実証されている。「誰かが動かしている WiFi の電波を、勝手に搬送波として使う」——物理現象のただ乗りとして純度が高い。

**技術の魅力**: 通信の定義は「情報を乗せて伝える」であり、必ずしも「自分で電波を出す」ではない。バックスキャッタはこの定義をギリギリ正当化する——送信エネルギーをほぼゼロに近づけながら情報を届けられるという非対称性。WiFi アクセスポイントは自分が「タグの搬送波」として使われているとは夢にも思っていない。しかも WiFi の電波は今やほぼどこにでもあるので、インフラ依存ゼロとは真逆の「世界中のWiFiインフラ全部を借りる」という逆説的な姿勢になる。

**本来どこで使われてるか**: 学術的な発端はワシントン大学（UW）の2013年の論文「Ambient Backscatter: Wireless Communication Out of Thin Air」（ACM SIGCOMM 2013）。TV 放送と WiFi を電源・搬送波に使うタグを実証し、同種の後継研究が WiFi Backscatter（2014）、Passive Wi-Fi（2016）として続いた。商用展開では Wiliot 社が Bluetooth パケットをバックスキャッタするパッシブタグを製品化し、食品・薬品のサプライチェーン向けに温度・鮮度モニタリングタグとして実用化している（BLE backscatter で、アンビエント WiFi とは搬送波が異なるが原理は同じ）。
出典: https://homes.cs.washington.edu/~gshyam/Papers/ambientbackscatter.pdf / https://dl.acm.org/doi/10.1145/2486001.2486015
