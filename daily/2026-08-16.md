### <a id="card-1"></a>🆕 1940年代の暗号が、今も"数学的に解読不能"なまま電波に乗っている——ナンバーステーションのワンタイムパッド 〔move: レガシー/廃止予定機能の蘇生 / 領域: ワイルドカード(諜報史・暗号)〕

**事実**: 短波帯には今も、単調な声が数字や文字の羅列だけを延々と読み上げる「ナンバーステーション」と呼ばれる放送局が点在している。多くは情報機関が海外に潜入した工作員へ一方向で指令を送るために運用していると見られ、暗号方式はワンタイムパッド(使い捨て乱数表)だと考えられている。鍵が本当にランダムでメッセージと同じ長さ以上あり、一度しか使われなければ、暗号文からは計算資源をいくら積んでも一切の統計的手がかりが得られない——これは1949年にクロード・シャノンが数学的に証明した「完全秘匿性」であり、"解読が困難"ではなく原理的に解読不可能という違いがある。

**何ができる**: 受信側は市販の短波ラジオ1台あれば足り、ログインも応答も要らないため、傍受者には「誰が聞いているか」はおろか「誰に向けた放送か」すら分からない。送信側もインターネットも衛星も光ファイバーも介さないため、地上のデジタルインフラを丸ごと監視・遮断しても止められない。ロシアのUVB-76(通称「ブザー」)はこの仕組みで数十年ブザー音を鳴らし続けており、観測者コミュニティの報告では2025年11月に1か月で24件・30種の単語を含む通信が確認され、観測史上もっとも活発な時期になったという。

**技術の魅力**: これはバグや脆弱性の話ではなく、正反対に「数学的に完璧な暗号」を運ぶ配送経路そのものが弱点になるという非対称性が効いている。国家級の敵に対抗する最新の答えが、耐量子暗号ではなく1930年代のラジオ技術と紙の乱数表だという皮肉。攻撃側にできることは復号への挑戦ではなく、送信アンテナや受信者本人という物理的実体を探すことだけに限られる。

**本来どこで使われてるか**: 冷戦期から各国の情報機関が、海外の非公式な工作員に暗号鍵の受け渡しなしで指令や合言葉を送るための一方向通信として使ってきた歴史があり、Priyom.orgのような監視コミュニティが世界中のナンバーステーションの周波数・放送スケジュールを今も継続的にカタログ化している。近年もロシア関連とされる局の活動が繰り返し報じられている。
出典: https://priyom.org/number-stations / https://www.radioworld.com/news-and-business/do-shortwave-numbers-stations-really-instruct-spies / https://n5ttt.substack.com/p/the-whispering-ghosts-of-the-airwaves

### <a id="card-2"></a>🔍 壊れたノードを守るための自己隔離機能が、正常なECUを黙らせる凶器になる——CANバスの"バスオフ"攻撃 〔move: サイドチャネル/副作用の利用 / 領域: 無線/組み込み/ハードウェア〕

**事実**: 自動車のほぼ全てのECU(エンジン・ブレーキ・エアバッグ等の制御ユニット)が通信に使うCANバスには、1990年代の規格(ISO 11898)の段階から「フォールト・コンファインメント」という自己防衛機構が組み込まれている。各ノードは自分の送受信エラーを内部カウンタ(TEC/REC)でひそかに数えており、閾値127を超えると"エラーパッシブ"に、255を超えると"バスオフ"状態になって自らバスから完全に切断される——1台の故障ノードが共有バス全体を壊れたフレームで埋め尽くすのを防ぐための、極めて健全な保護設計だ。

**何ができる**: 2016年、Cho and Shinはこの仕組みを逆手に取れることを示した。攻撃者が改造したOBD-IIドングルや乗っ取ったインフォテインメント経由でバスにわずかなビットを注入できれば、狙った正規ECUが送信した直後のフレームにだけぶつけてビットエラーを起こし続け、そのECU自身のエラーカウンタを人為的に255超まで押し上げられる。すると標的ECUは自分の判断で"バスオフ"に入り、以後いっさい発話しなくなる——ブレーキ制御やエアバッグ制御を、マルウェアもバッファオーバーフローも使わずに沈黙させられる。

**技術の魅力**: 「壊れた1台が全体を巻き込まないための保護機能」が、そのまま「健全な1台を選んで黙らせる攻撃のスイッチ」に反転する非対称性が肝。攻撃者は保護機構を破っているのではなく、規格通りに正しく動く保護機構に、標的ECUが自分自身を正しく信じ込ませているだけ。標的側のファームウェアには一切の改竄がないため、事後に基板を調べても異常は見つからない。

**本来どこで使われてるか**: バスオフを含むフォールト・コンファインメントはCANプロトコル(ISO 11898-1)の必須仕様で、配線劣化やトランシーバ故障を起こした1ノードが共有バスをジャムし続けるのを防ぐため、自動車に限らず産業用PLCネットワークや航空機の一部システムでも標準的に使われている。Cho and Shinの実験はACM CCS 2016で発表され、実車でバスオフ攻撃が成立することを示した。
出典: https://dl.acm.org/doi/10.1145/2976749.2978302 / https://medium.com/@mohammednumeir13/can-protocol-can-error-detection-and-fault-confinement-c13c2cdea2ed

### <a id="card-3"></a>💡 ファイル共有の道案内網が、契約もサーバーもなしにデータそのものを預かる金庫になる——BitTorrent DHTのBEP44 〔move: 仕様の目的外利用 / 領域: データ/同期/ストレージ〕

**事実**: BitTorrentのMainline DHT(Kademlia系の分散ハッシュテーブル)は本来、トラッカーサーバーなしに同じトレントを持つピア同士を見つけ合うためだけの仕組みだ。ところが2014年に追加された拡張BEP 44は、この探索用インフラに「トレントとは無関係な任意データそのものを最大1000バイトまで保存・取得できる」機能を静かに付け加えた。データの種類は2つ——内容のSHA1ハッシュをキーにする書き換え不能な immutable item と、公開鍵(32バイトのEd25519)をキーにし秘密鍵の署名で誰でも中身を更新できる mutable item——で、後者は改竄されたシーケンス番号への巻き戻しを拒否する仕組みも持つ。

**何ができる**: mutable itemを使えば、世界中で既に稼働している数百万台のBitTorrentクライアントを間借りするだけで、「公開鍵というアドレスに対して値を引ける、サーバーレスなキー→値ポインタ」がタダで手に入る。中身を更新できるのは対応する秘密鍵の持ち主だけなので、検閲耐性のある"最新版マグネットリンク"の告知や、運営者不在のデッドドロップ、公開鍵だけを頼りにした簡易メッセージング(掲示板)まで組める。実際BEP 46はこの仕組みを使い、マグネットリンクのアドレス自体は変えずに中身のトレントだけを差し替える更新機構として正式に採用している。

**技術の魅力**: 「ピアを見つける」ためだけのメタデータ交換網が、新しいサーバーを一切建てずに汎用のキー・バリューストアへ化けるところが効いている。運営者のいないインフラを"借用"するので、差し止める相手(サーバーの持ち主やドメイン)が存在しない——値はKademliaのXOR距離で決まる、その時々の"たまたま近いノード群"の中にしか存在しない。

**本来どこで使われてるか**: Mainline DHTはBEP 5で標準化された、中央トラッカーなしでピアを発見するための仕組みで、libtorrent/qBittorrent・Transmission・µTorrentなど主要クライアントがほぼ標準搭載している。BEP 44の任意データ格納は、まさにBEP 46のミュータブルトレント更新を支えるために設計されたもので、`dhtkv`のような小さなツール群がその生のput/getプリミティブを汎用キー・バリューストアとして転用している。
出典: https://www.bittorrent.org/beps/bep_0044.html / https://www.bittorrent.org/beps/bep_0046.html / https://github.com/max-mapper/dhtkv
